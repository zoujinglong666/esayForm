🎯 核心功能特性

多种表单控件
支持 input、select、date-picker、slider、radio、checkbox 等
表单验证
内置验证规则，支持自定义验证器
自定义插槽
灵活的插槽系统，支持完全自定义渲染
响应式设计
自适应布局，支持移动端优化
复合表单
支持嵌套和组合表单项
国际化
内置多语言支持

💻 基础用法示例

<template>
  <PlusQuery
    v-model="queryParams"
    :columns="queryColumns"
    @submit="handleSubmit"
  />
</template>

<script setup>
import { ref } from 'vue'
import { PlusQuery } from '@/components/PlusQuery'
import type { PlusColumn } from '@/components/PlusTable/types'

const queryParams = ref({
  keyword: '',
  status: '',
  dateRange: []
})

const queryColumns = ref<PlusColumn[]>([
  {
    label: '关键词',
    prop: 'keyword',
    valueType: 'input',
    placeholder: '请输入关键词搜索'
  },
  {
    label: '状态',
    prop: 'status',
    valueType: 'select',
    options: [
      { label: '全部', value: '' },
      { label: '启用', value: 'active' },
      { label: '禁用', value: 'inactive' }
    ]
  },
  {
    label: '创建时间',
    prop: 'dateRange',
    valueType: 'date-picker',
    fieldProps: {
      type: 'daterange',
      format: 'YYYY-MM-DD'
    }
  }
])

const handleSubmit = (formData) => {
  console.log('查询参数:', formData)
}
</script>

⚡ 开发提示

  • 使用 order 属性控制表单项的排列顺序
  • 通过 fieldProps 传递具体表单控件的属性
  • 使用 rules 数组配置表单验证规则
  • 利用 hideInForm 控制条件显示/隐藏
  • 自定义插槽可以实现完全个性化的表单控件
